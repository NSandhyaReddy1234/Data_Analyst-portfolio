# Swiggy Sales Analysis

## Project Overview
Analysed Swiggy sales data using Microsoft Excel
to identify sales trends and business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Analysis

## Key Activities
- Cleaned and organised sales data.
- Analysed sales performance.
- Created interactive dashboards.
- Used Pivot Tables and Charts for reporting.

## Project Outcome
Developed an interactive sales dashboard
to understand business performance.
